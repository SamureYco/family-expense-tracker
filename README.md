# 💰 Family Expense Tracker

## 📌 Project Description

Family Expense Tracker is a web application that allows users to manage personal or family finances by tracking income and expenses.

The system is connected to a Supabase cloud database, where all transactions are stored and retrieved in real time.

This project demonstrates frontend development skills and basic backend integration using an external database service.

---

## 🎯 Purpose of the Project

The goal of this project is to:

- Practice CRUD operations (Create and Read)
- Learn how to connect a frontend application to a database
- Understand how APIs work using Supabase
- Build a simple but functional financial tracking system

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES Modules)
- Supabase (Cloud Database)

---

## ✨ Features

- Add income and expense transactions
- Store data in a cloud database (Supabase)
- Display transactions in real time
- Clean and simple user interface
- Automatic data refresh after adding records

---

## 🗄️ Database Structure

The project uses a Supabase table called:

### transactions

Fields:

- id (primary key)
- type (Income / Expense)
- description (text)
- amount (number)
- created_at (timestamp)

---

## ⚙️ How It Works

1. User enters transaction data in the form
2. JavaScript sends data to Supabase
3. Data is stored in the database
4. Application fetches and displays updated list automatically
